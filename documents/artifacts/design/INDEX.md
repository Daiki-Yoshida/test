# Design Router

- contract completeness, public guarantees, contract change level → `CONTRACTS.md`
- responsibility / split / graduation decisions → `RESPONSIBILITY.md`
- consumer-neutral concept meaning / sharing → `CONCEPT_ALTITUDE.md`
- mutable state / cross-boundary consistency ownership → `STATE_AND_CONSISTENCY.md`
